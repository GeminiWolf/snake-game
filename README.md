# Snake Game

Classic Snake game built with React 18 and Vite.

## Features

- Classic snake gameplay with wall collision detection
- WASD and arrow key controls
- Score tracking with localStorage high scores
- Progressive speed increase as you eat more food
- Prevents 180° turns that would cause instant collision

## Development

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```

## Deployment

This game is ready for deployment to Vercel. Simply connect the repository to your Vercel project and it will deploy automatically on every push to the main branch.

## How to Play

1. Click "Start" and enter your name
2. Use arrow keys or WASD to control the snake
3. Eat the red food to grow and increase your score
4. Avoid hitting the walls or yourself
5. Try to beat the high scores!
